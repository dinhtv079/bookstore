# 📚 Nhà Sách Online

Website bán sách đơn giản viết bằng HTML, CSS, JavaScript thuần — không cần cài đặt gì.

## Tính năng
- Danh sách sách theo danh mục (Văn học, Kỹ năng, Kinh tế, Khoa học, Thiếu nhi, Tin học)
- Tìm kiếm theo tên sách / tác giả, sắp xếp theo giá hoặc tên
- Giỏ hàng: thêm, tăng/giảm số lượng, xóa; lưu lại khi tải lại trang
- Miễn phí giao hàng cho đơn từ 300.000đ (dưới mức này phí 30.000đ)
- Form đặt hàng (họ tên, số điện thoại, địa chỉ, ghi chú)

## Cách chạy
Mở file `index.html` bằng trình duyệt.

## Thêm / sửa sách
Mở file `books.js` và chỉnh danh sách `BOOKS`.

## Đưa web lên mạng (GitHub Pages)
Vào repo trên GitHub → **Settings** → **Pages** → mục *Branch* chọn `main` → **Save**.
Sau 1–2 phút web sẽ có địa chỉ: `https://dinhtv079.github.io/bookstore/`

> Lưu ý: đơn hàng hiện chỉ lưu trong trình duyệt (localStorage), chưa gửi về máy chủ.
